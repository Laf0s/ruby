# Лабораторна робота №5 (Варіант 35)

**Тема:** Об'єктно-орієнтоване програмування в Ruby  
**Мета роботи:** Засвоїти основи об’єктно-орієнтованого програмування у Ruby.

## Завдання
1. **Завдання 1:** Ієрархія класів: базовий клас `Publication` та класи-нащадки `Book`, `Magazine`, `Newspaper`, `Comic`.
2. **Завдання 2:** Конструктори об'єктів (`initialize`) з іменованими аргументами та викликом `super` для ініціалізації базових полів.
3. **Завдання 3:** Інкапсуляція: робота з макросами `attr_accessor`, `attr_reader` та створення сеттера `circulation=` із валідацією значення.
4. **Завдання 4:** Модифікатори доступу (`public`, `protected: raw_pages`, `private: calculate_sheets`).
5. **Завдання 5:** Поліморфізм: реалізація методів верстки (`layout`) та опису (`info`) для кожного виду видання.
6. **Завдання 6:** Перевизначення методу предка зі зверненням до оригіналу через `super` (`Comic#print_run`).
7. **Завдання 7:** Робота з модулями: включення міксину в екземпляри (`include BarcodePrintable`) та розширення методів класу (`extend Searchable`).
8. **Завдання 8:** Пошук елементів у колекції за автором (`find_by_author`) та за рубрикою (`find_by_category`).
9. **Завдання 9:** Синглтон-метод класу (`Publication.standard_dpi`) та його перевизначення в класі-нащадку (`Comic.standard_dpi`).
10. **Завдання 10:** Синглтон-метод окремого екземпляра та перевизначення методу предка для одного об'єкта (`rare_book.to_s`).

## Запуск

ruby lab5/main.rb
