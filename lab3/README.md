# Лабораторна робота №3 (Варіант 35)

## Завдання
1. **Завдання 1:** Створити хеш, який містить 10 страв ресторану (назва страви => вартість у гривнях).
2. **Завдання 2:** Перетворити цей хеш у індексний масив та вивести його.
3. **Завдання 3:** Вивести початковий хеш відсортованим за назвою страви або її ціною (вибір з клавіатури).
4. **Завдання 4:** Вивести 3 страви, які мають найкоротшу назву.
5. **Завдання 5:** Вивести 5 найдешевших страв, які мають ненульову ціну.
6. **Завдання 6:** Перевірити наявність страви, назва якої введена з клавіатури, та вивести її ціну.
7. **Завдання 7:** Обчислити загальну вартість замовлення (по одній порції кожної страви).
8. **Завдання 8:** Перевірити наявність страв без вказаної ціни (або з нульовою ціною) та ввести їхню вартість з клавіатури.

## Запуск
```bash
ruby lab3/main.rb
```
