# Лабораторна робота №2 (варіант 35)

## Мета роботи

Закріпити роботу з одновимірними та двовимірними масивами в Ruby, порівняти
керуючі конструкції з ітераторами, а також опрацювати текстові файли.

## Структура роботи

### Блок 1. Одновимірні масиви (`block1.rb`)

1. **Завдання 5.** Для масиву чисел знайти всі елементи, більші за його
   середнє арифметичне:
   - за допомогою `while`, `for` та `if`;
   - за допомогою `sum` і `select`.
2. **Завдання 6.** До парних елементів додати перший елемент масиву, а до
   непарних — останній. Перший і останній елементи не змінювати:
   - за допомогою `while` та `if / else`;
   - за допомогою `map.with_index`.

### Блок 2. Двовимірні масиви (`block2.rb`)

3. **Завдання 11.** Обчислити суму та середнє арифметичне елементів головної
   діагоналі матриці:
   - циклом `while` з прямим доступом `matrix[i][i]`;
   - ітераторами `map` та `sum`.
4. **Завдання 12.** Знайти номери рядків, усі елементи яких дорівнюють нулю:
   - циклом `until` із достроковим виходом `break`;
   - ітераторами `each_with_index`, `all?` та `filter_map`.

У Ruby індексація масивів починається з нуля. Тому програма виводить і
внутрішні індекси рядків, і їхні номери для користувача (з нумерацією від 1).

### Блок 3. Робота з файлами (`block3.rb`)

5. **Завдання 9.** Опрацювати конфігураційний файл:
   - прибрати символ переведення рядка та зайві пробіли;
   - пропустити порожні рядки й рядки-коментарі, що починаються з `#`;
   - реалізувати це через `File.foreach`, а також через `File.open` і
     `readlines`.
6. **Завдання 10.** У файлі `template.html` замінити всі входження `{{YEAR}}`
   на `2026` і зберегти зміни:
   - через `File.read`, `gsub` та `File.write`;
   - через блокову форму `File.open` для читання і запису.

Тимчасові файли `app.conf` і `template.html` створюються під час виконання
`block3.rb`, а після демонстрації результату видаляються.

## Запуск
Запустити всі завдання:

```bash
ruby lab2/main.rb
```

Запустити окремий блок:

```bash
ruby lab2/block1.rb
ruby lab2/block2.rb
ruby lab2/block3.rb
```
