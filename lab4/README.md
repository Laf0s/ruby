# Лабораторна робота №4

**Тема:** Методи в мові Ruby  
**Предметна область:** Студент та навчальний процес (ІПЗ-33)

## Завдання
1. **Завдання 1:** Метод із аргументами за замовчуванням та перевизначення методу.
2. **Завдання 2:** Метод із необов'язковими іменованими параметрами (`keyword arguments`).
3. **Завдання 3:** Логічний (предикатний) метод (`passed?`).
4. **Завдання 4:** Метод-оператор (`+`) та метод присвоювання (`score=`).
5. **Завдання 5:** Метод із масивом у якості аргументу та splat-параметрами (`*args`).
6. **Завдання 6:** Псевдонім методу (`alias`).
7. **Завдання 7:** Метод-блок із явним аргументом (`&block`).
8. **Завдання 8:** `yield`-методи з аргументом і без нього з перевіркою `block_given?`.
9. **Завдання 9:** Об'єкти `Proc` без аргументів і з аргументами (демонстрація гнучкості аргументів та поведінки `return`).
10. **Завдання 10:** Об'єкти `lambda` без аргументів і з аргументами (демонстрація суворості аргументів та локального `return`).

## Запуск
```bash
ruby lab4/main.rb
```
